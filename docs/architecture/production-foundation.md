# 4Short production foundation

## Границы контуров

- Vercel/Sites обслуживает только публичный Next.js и статическую оболочку кабинета.
- `api.4short.ru` хранит сессии, PII, проекты, деньги и выдаёт подписанные S3 URL.
- PostgreSQL — единственный источник истины для состояния и очереди.
- Media-worker не хранит пользовательское состояние между jobs.
- Пользовательские media-объекты находятся в приватных Timeweb Cloud S3 buckets.
- Оплата идёт через интернет-эквайринг Т‑Банка; карточные реквизиты 4Short не получает.

## Провайдеры inference

Хранилище и control plane не определяют поставщика моделей. STT и LLM подключаются через
адаптеры и выбираются конфигурацией worker.

- OpenRouter вызывается только с явным allowlist моделей, `data_collection=deny` и `zdr=true`.
- `openrouter/auto`, `openai/*` и `anthropic/*` запрещены политикой по умолчанию.
- DeepSeek можно использовать напрямую без OpenRouter.
- SpeechKit остаётся стартовым benchmark baseline для русского STT, а не обязательным
  единственным провайдером.
- Новый провайдер допускается в production только после одинакового regression-набора:
  русская разговорная речь, таймкоды слов, диаризация, JSON adherence, latency и цена.
- Решение о модели хранится в job metadata и `provider_usage_costs`, поэтому качество и
  себестоимость сравниваются по реальным проектам, а не по рекламным benchmark.

Транскрипты могут содержать персональные данные. Зарубежный inference включается только для
провайдеров из allowlist с подтверждённой политикой хранения и после отражения трансграничной
обработки в пользовательском согласии и юридических документах.

## Гарантии команд

Каждая изменяющая команда получает `Idempotency-Key`. API берёт transaction-level advisory lock,
сверяет hash тела запроса и возвращает ранее сохранённый ответ при безопасном повторе.

Media job имеет lease и heartbeat. Исчезнувший worker не делает задачу потерянной: lease sweep
возвращает её в очередь или завершает после исчерпания попыток. Этапы передают друг другу только
сохранённые артефакты.

## Минуты

Баланс хранится в секундах по buckets. Резерв атомарно блокирует buckets в порядке:

1. текущий период;
2. перенос;
3. купленные пакеты.

Повторный исходник определяется SHA-256 внутри workspace. Транзакции append-only; release/refund
добавляет компенсирующую запись, а не исправляет историю.

## Версии

- Пресет неизменяем: сохранение создаёт `style_versions`.
- Проект хранит snapshot настроек в `project_versions`.
- Клип компилируется в canonical EDL.
- `render_hash` включает EDL, source hash и renderer version.
- Cache hit использует готовый artifact без повторного FFmpeg.

## Worker 2/4 ГБ

- один тяжёлый job;
- `-threads 2`, streaming decode;
- scratch проверяется до запуска;
- source читается через временный signed range URL;
- полный YouTube source потоково multipart-загружается в S3;
- job directory удаляется после загрузки результата;
- 2 ГБ режим ограничивает worker RSS до 1,4 ГБ.

## Что нельзя выдавать за готовое

Если credential или provider отсутствует, API возвращает явный `*_NOT_CONFIGURED`. UI не запускает
таймер, не рисует успешный рендер и не списывает минуты. Face analysis пока может вернуть безопасный
static-crop fallback с `FACE_MODEL_NOT_INSTALLED`; это предупреждение, а не скрытая имитация трекинга.
